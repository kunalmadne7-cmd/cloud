# Dr Lal PathLabs × Thyrocare: hypothetical acquisition

The scenario: DLPL buys API Holdings' (PharmEasy's) ~51% stake in Thyrocare and makes the
mandatory SEBI open offer for another 26%.

| File / folder | What it is |
|---|---|
| [`DEAL_PRIMER.md`](DEAL_PRIMER.md) | **Start here.** The deal explained from the basics: both businesses, the ownership history, SEBI takeover mechanics, deal sizing, funding and EPS maths, risks. |
| [`DOWNLOAD_CHECKLIST.md`](DOWNLOAD_CHECKLIST.md) | Every filing needed, where it goes, and how to fetch it. **No PDFs have been downloaded yet**: the network policy blocked all company, exchange and SEBI sites. |
| `Dr_Lal_PathLabs/` | Filing folders (01 Annual Reports … 06 Other). |
| `Thyrocare/` | Same, plus `07_Deal_Filings/` for shareholding patterns, Docon stake-sale and pledge filings, and the 2021 open offer. |
| `fetch/` | `fetch_filings.py` (downloads and verifies PDFs), `harvest_links.py` (lists PDF links on an IR page), `manifest_known_urls.json`. |

Numbers in the primer come from press reports of the filings, found via web search, and are
marked where derived or still to be verified against the annual reports.
